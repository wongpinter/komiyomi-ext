# Readest EPUB Library and Reader UI/UX Research

**Checked:** 2026-10-17. **Implementation snapshot:** [`readest/readest` commit `420a5931cba015c9c73e59e428b4fcfd1c11fc7f`](https://github.com/readest/readest/commit/420a5931cba015c9c73e59e428b4fcfd1c11fc7f), plus Readest's live first-party docs checked the same day. The repository is cross-platform (web/desktop/mobile); exact chrome differs by platform. This report separates observed Readest behavior from recommendations for Komiyomi Ext.

## Findings from Readest

### Library: cover-first, quick to resume, scalable

- Readest opens to a library/bookshelf with **Grid as the default** and **List as a dense alternative**. Its docs describe grid as visual browsing and list as useful for large collections; library search filters metadata (title, author, tags, series). ([Library docs](https://readest.com/docs/library))
- The implementation makes the cover a portrait card (28:41), with title and concise reading/status information beneath or overlaid; list view exposes more metadata. It supports a responsive, virtualized cover grid, rather than rendering every book at once. ([`BookItem.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/library/components/BookItem.tsx#L120-L225), [`BookshelfStream.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/library/components/BookshelfStream.tsx#L42-L53), [virtualized grid](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/library/components/BookshelfStream.tsx#L287-L384))
- A **Recently read** shelf acts as a quick-resume strip. Progress is glanceable as a percentage, optionally with remaining time; finished, unread, and on-hold books use explicit status labels instead. ([Library docs](https://readest.com/docs/library), [`ReadingProgress.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/library/components/ReadingProgress.tsx#L17-L68))
- Search, import (`+`), grid/list, selection, and library options are grouped in the library header. The import affordance also appears inline after books in the stream. Full-text library search is a separate explicit mode from metadata search. ([`LibraryHeader.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/library/components/LibraryHeader.tsx#L85-L180), [`Bookshelf.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/library/components/Bookshelf.tsx#L864-L891), [Library docs](https://readest.com/docs/library))
- Book-level secondary actions (details, narration, download/offline, upload) are contextual and carry accessible labels/titles, rather than replacing the primary cover-open action. ([`BookItem.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/library/components/BookItem.tsx#L252-L321))

### Reader: calm page, controls on demand

- Readest hides reading chrome until requested: tapping/clicking the center toggles the toolbars. Its docs place **back/library, title, TOC, bookmark, settings, and secondary actions** in the top toolbar; the bottom shows chapter/book progress, page/time information, and TTS. ([Reading docs](https://readest.com/docs/reading), [`HeaderBar.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/HeaderBar.tsx#L149-L195))
- The code keeps controls compact but preserves larger touch hit zones: approximately 18px glyphs, 32px visual buttons, and 44px mobile hit areas. Mobile navigation groups named actions (TOC, color/theme, progress, font/layout, speak) in a bottom bar; tapping progress opens a focused panel with a slider, position, and previous/next navigation instead of cramming all controls into the bar. ([`HeaderBar.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/HeaderBar.tsx#L207-L263), [`NavigationBar.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/footerbar/NavigationBar.tsx#L28-L80), [`NavigationPanel.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/footerbar/NavigationPanel.tsx#L56-L142))
- Icon use follows action semantics: library/back, contents/sidebar, bookmark, translation/annotation, TOC, theme, progress, typography/layout, and speech. Mobile controls pair icons with visible labels; other icon buttons use accessible names/titles. Active states change icon color, so state should not depend on color alone. ([`HeaderBar.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/HeaderBar.tsx#L207-L263), [`NavigationBar.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/footerbar/NavigationBar.tsx#L28-L80), [`BookItem.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/library/components/BookItem.tsx#L252-L321))
- Position is exposed as both chapter and book progress; the reader can show page, percentage, publisher reference-page labels, and an optional persistent progress bar. Resume is an explicit product flow: the Recently read shelf and mobile widgets open at the last reading position. ([Reading docs](https://readest.com/docs/reading), [Library docs](https://readest.com/docs/library))

### TOC and search: keep navigation distinct from text search

- Readest's TOC is inside the reader sidebar, alongside bookmarks, notes, and in-book search. Its docs say the active section stays highlighted, a **Current position** row appears beneath it, page numbers are shown, and long headings wrap. ([Reading docs — TOC & search](https://readest.com/docs/reading#toc-search))
- The implementation uses nested, expandable, virtualized TOC rows; it keeps the current section expanded and scrolls it into view. A separate current-position row gives a direct return-to-reading-location action. ([`TOCView.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/sidebar/TOCView.tsx#L953-L1002), [active tracking](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/sidebar/TOCView.tsx#L1319-L1412), [virtual list](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/sidebar/TOCView.tsx#L1414-L1518), [current-position row](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/sidebar/TOCItem.tsx#L1119-L1208))
- **Important distinction:** Readest's sidebar search is full-text search, with chapter-grouped excerpts and jump-to-match behavior; its TOC docs do not describe a chapter-title-only filter. ([Reading docs — TOC & search](https://readest.com/docs/reading#toc-search), [`SearchResults.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/sidebar/SearchResults.tsx#L183-L273))
- Its sidebar is leading/left anchored on desktop and expands to full width on mobile, with scrim, swipe dismissal, and drag resize. That position is an implementation choice, **not a requirement to copy**. ([`SideBar.tsx`](https://github.com/readest/readest/blob/420a5931cba015c9c73e59e428b4fcfd1c11fc7f/apps/readest-app/src/app/reader/components/sidebar/SideBar.tsx#L164-L239))

## Recommendations for Komiyomi Ext (inference)

1. **Make EPUB a library destination, not an import utility.** Selecting the EPUB feature should open a dedicated, cover-first EPUB shelf. Default to a responsive grid; offer a list toggle for dense/metadata browsing. EPUB-only filtering is an adaptation—Readest's library itself is multi-format.
2. **Let the cover be the primary action.** Tap opens or resumes the book at its latest saved locator. Put title and a small progress/status line below it. Reserve visible secondary controls for import/search/view mode; place delete, re-import, and other infrequent actions in a per-book overflow or selection mode.
3. **Use cover cards as scannable, not decorative, UI.** Preserve portrait aspect ratio, readable titles, a missing-cover fallback, and clear `Unread` / `Reading · %` / `Finished` states. Use lazy/virtualized grid content so a large local library does not create an enormous view tree.
4. **Keep reader chrome quiet but discoverable.** Use center tap to show/hide; place Back, Contents, Bookmark, and Font/Layout among the primary actions. Keep advanced actions in overflow/settings. On narrow screens, use a small labeled bottom action row and open focused panels for navigation/progress rather than displaying many tiny icons.
5. **Honor the user's requested right-side TOC sheet.** Reuse Readest's useful behavior—nested virtual rows, current-section tracking, wrapped headings, and a distinct “Current position” jump—but anchor the sheet on the right to match the user's Moon+ Reader preference. Make the TOC's chapter-title filter explicit and separate from whole-book text search; Readest's documented/source implementation search is full-text, not a TOC filter.
6. **Treat icons as shortcuts, not unlabeled controls.** Use familiar icons with visible text for primary mobile actions; give every icon-only control a localized accessibility label and tooltip/content description. Keep touch targets at least 44px in the Readest reference implementation; for native Compose, use at least 48dp hit areas (the Android recommendation and Material `IconButton` default), and communicate selected/active state with more than color alone. ([Android accessibility guidance](https://developer.android.com/guide/topics/ui/accessibility/apps), [Compose `IconButton`](https://developer.android.com/reference/kotlin/androidx/compose/material3/IconButton.composable))
7. **Keep manga untouched.** Add a separate EPUB library entry/activity/navigation route and EPUB-specific preferences; do not re-style the manga grid or reader toolbar to match the novel interface.

## Caveats

- The public docs describe platform-neutral behavior while source code is a cross-platform app. Desktop, web, and native mobile controls differ; use mobile source paths for mobile-specific conclusions.
- Readest supports many formats, syncing, search, and library organization beyond Komiyomi Ext's local EPUB reader. Recommendations above are scoped adaptations, not claims that the local app already supports those features.
- This is a source/documentation review, not a screenshot-based visual audit of a running Readest build or the local app. Verify spacing, contrast, keyboard behavior, talkback labels, and tablet layout on-device before implementation sign-off.
