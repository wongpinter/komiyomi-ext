# EPUB layout controls

Open a reflowable EPUB, reveal controls, then choose **EPUB reading settings → Page layout**.
These settings apply to EPUB books only; they do not change the manga viewer.

| Setting | Range / choices | Meaning |
| --- | --- | --- |
| Horizontal margins | 0.0–4.0, step 0.1 | Factor relative to Readium's default horizontal margin; not pixels. Does not set independent top/bottom margins. |
| Line spacing | 1.0–2.0, step 0.1 | Line-height multiplier relative to text size. |
| Paragraph spacing | 0.0–2.0, step 0.1 | Vertical spacing in rem (root text size). |
| First-line indent | 0.0–3.0, step 0.1 | Paragraph indentation in rem. |
| Text alignment | Default, Start, Left, Right, Justified | Start follows the reading direction. Center/End are intentionally not offered because Readium 3.2 maps them to Start. |

## Apply, cancel and defaults

- Numeric dialogs show the current stored value, or **Default value** when unset.
  An unset slider starts at a usable adjustment position; opening or applying an untouched
  default does not create an override. Move the slider to select a custom value.
- Changes remain local drafts until **Apply**. Cancel, Back, outside dismissal or recreation
  before Apply does not save a draft. Layout changes are not live-previewed while dragging,
  avoiding repeated expensive WebView reflow.
- **Default value** in a numeric dialog clears just that property; Default in alignment clears
  that alignment override. Other overrides and the current custom-style mode are retained.
- Applying a non-default line, paragraph or alignment value enables custom layout
  (`publisherStyles = false`) as required by Readium. Margins work independently and do not
  disable publisher styles. Some writing systems/book styles can limit these controls.
- **Restore publisher layout** clears the four numeric overrides, alignment and custom-style
  flag. It does not reset font family, text size, scrolling/pagination or reading position.
  The publisher's original CSS may include its own margins and paragraph formatting.
- All preferences are saved per imported copy in the EPUB reader's per-book store. Other books,
  manga preferences and source EPUB files are unchanged.
- The current locator is checkpointed before a changed preference set is submitted to the
  existing navigator. No publication is reopened or book-wide index generated by this panel.
- Layout controls are omitted for fixed-layout books. Independent vertical margins,
  column count, custom CSS, letter/word spacing and user-defined presets remain future work.

## Verification and limits

Policy tests cover safe numeric bounds (including NaN/infinities), actual supported
alignments, publisher-style activation, field reset and whole-panel reset without dropping
other preferences. Store tests cover persistence across store recreation, isolation between
books, and preserving fonts/mode when restoring publisher layout.

Verification (2026-10-17): ordered spotlessApply → spotlessCheck → assembleDebug passed.
Seven layout policy tests, eleven store tests, five font tests and eight importer tests
passed (31 total; importer tasks reused valid cached results). git diff --check passed.

Android dialog rendering, TalkBack/keyboard interaction, actual CSS effects and exact latest
position across reflow/rotation/restart require a real device. No UI/performance pass is
claimed from compilation or JVM tests alone, particularly for the 1 GB omnibus fixture.
